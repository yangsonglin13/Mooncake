🎯 总结

🥮 Mooncake 特点

  • • 集中式 Master：元数据管理集中，存在单点瓶颈
  • • 分离缓存设计：Local Cache + Global Cache 分层
  • • 跨进程访问：所有元数据操作需 RPC 通信
  • • NVIDIA 生态：成熟的 GPU 支持
  • • 适合场景：中等规模 LLM 推理集群

🚀 Yuanrong 优势

  • • 分布式元数据：一致性哈希，无中心瓶颈
  • • 统一内存池：Arena + Jemalloc 高效管理
  • • 共享内存直读：零拷贝，无需跨进程 RPC
  • • 线性扩展：适合超大规模部署
  • • 适合场景：大规模训练/推理集群
